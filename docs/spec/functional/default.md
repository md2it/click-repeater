# DEFAULT

- Marks which entry the shortcut launches
- Only one entry can be the default at a time
- The shortcut launches the default, if one is set
- Not currently exposed in the UI:
   - No button or control lets the user view or change which entry is the default
   - The underlying data (which entry, if any, is marked default) is preserved and still consulted by the shortcut
   - This is a temporary state; a UI for it may be reintroduced later
